1 小时用 VPS + Cloudflare + WordPress 建一个企业官网

全流程实操 · 以我自己的玻纤布生意为例

一个企业官网不需要找人花几千块。有一台 VPS、一个域名，1 小时就能上线。下面每一步都是我自己走过的流程。

第 1 步：买一台 VPS（10 分钟）

配置不用高，2 核 2GB 就够跑 WordPress + 宝塔。线路要选国内访问稳的，参考选购对比，我自己用的是 VMRack ★ 的洛杉矶 2 核 2GB。系统选 Debian 或 CentOS 都行，记下 IP 和 root 密码。

第 2 步：域名解析到 VPS（5 分钟）

域名在哪买的就在哪解析，或者托管到 Cloudflare（免费，还能挡一层攻击）。加一条 A 记录：主机名填 @ 或 www，值填 VPS 的 IP。解析生效一般几分钟。

第 3 步：装宝塔面板（10 分钟）

SSH 连上 VPS，执行宝塔官方安装命令（以 bt.cn 官网最新命令为准）：

yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh ed8484bec

装好后按提示打开面板地址，登录进去，一键装 LNMP 环境（Nginx + MySQL + PHP）。

第 4 步：一键部署 WordPress（10 分钟）

宝塔面板 → 软件商店 → 一键部署 → WordPress。填域名、数据库名和密码，点部署。部署完打开域名，就能看到 WordPress 安装界面，按提示填站点标题、管理员账号，5 分钟装好。

第 5 步：换主题，建产品页（20 分钟）

企业站不用花哨的主题，选个干净的免费主题就行。重点是把产品内容做好。以玻纤布生意为例，产品页至少要有：

  • 产品规格表：比如 7628、1080、2116 三种布的克重、幅宽、用途；
  • 产品图片和应用场景；
  • 询价表单：姓名、电话、要什么规格、要多少量，客户填完你就能收到。

内容真实、规格清楚，比花里胡哨的设计重要得多。

第 6 步：上 SSL 证书（5 分钟）

宝塔面板 → 网站 → 设置 → SSL → 申请免费的 Let's Encrypt 证书，开启强制 HTTPS。浏览器地址栏有了小锁，客户才敢填表单。

第 7 步：做好备份（5 分钟）

宝塔计划任务里加两条定时备份：网站文件每天备份一次，数据库每天备份一次，备份存到另一台机器或对象存储。站可以重建，客户询价数据丢了就找不回来。

这样建站要花多少钱

  • VPS：$9.99/月起（2 核 2GB，见选购对比）；
  • 域名：每年几十块；
  • Cloudflare、宝塔、WordPress、SSL 证书：免费。

一年成本不到一千块，就有了一个自己的企业官网，还能拿来接客户询价。
